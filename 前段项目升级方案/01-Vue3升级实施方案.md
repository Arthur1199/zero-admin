# zero-ui Vue 3 升级实施方案

实施与续验日期：2026-10-08～2026-11-16。源码范围为 `zero-ui` 和说明文档；Java、SQL、后端模板和权限定义未修改。已按用户明确许可新建、修改5条验收记录并上传公开logo3次，完整对象和证据见第二份文档；用户决定保留，未执行删除、恢复或清理。真实登录会正常产生会话和登录日志。

## 1. 升级目标与兼容边界

后续授权变更（2026-11-16）：用户另行授权必要的Java侧修改以修复Swagger故障。本次仅将父POM的SpringDoc从2.6.0调整到2.8.17，在SecurityConfig补齐文档子路径GET规则，并增加隔离回归测试及测试依赖；前述“Java未修改”描述前端迁移阶段，不适用于本次后续修复。未修改业务接口、异常处理器、数据库或权限定义。

目标栈为 Vue 3 + Vite + Element Plus + Vue Router 4 + Vuex 4。继续使用 JavaScript、Options API、原 Vuex 模块和若依页面结构，不引入 Pinia、TypeScript 或 Vue 2 兼容运行时。

保留接口路径、HTTP 方法、JSON 字段、Token、谷歌验证、分页、下载和历史上传字段。普通数据读取 `data`，分页读取 `rows/total`；不要求 Java 接口迁移。

支持 Chrome/Edge 111+、Firefox 114+、Safari/iOS 16.4+；实际 Chrome、Edge、Safari 仍需在目标环境验收。Playwright 的 Chromium/WebKit 不等于已验证用户安装的 Chrome/Safari。保留八种主题，允许组件细节变化。

版本以package.json和package-lock.json为准；锁文件已生成且未被忽略，提交时须纳入版本控制，本轮未执行Git提交或推送。禁止使用`--force`或`--legacy-peer-deps`掩盖冲突。原配置文件保留作历史参考，npm脚本实际使用Vite，不再调用Vue CLI/Webpack。

## 3. 构建、入口、图标

- 新增`vite.config.mjs`和根HTML入口；使用createApp注册现有全局方法、组件、指令、字典插件和Element Plus中文语言包。
- 保留`dev/build:prod/build:stage/preview`命令。开发默认80，预览9526；端口仍支持启动覆盖。
- 环境变量由`VUE_APP_*`迁移为`VITE_APP_*`，读取`import.meta.env`。开发、staging、生产前缀仍为`/dev-api`、`/stage-api`、`/prod-api`。
- Vite代理仍指向admin 9099，并保留`/v3/api-docs`代理；可通过`VITE_DEV_PROXY_TARGET`和`VITE_DEV_PORT`覆盖开发环境，不修改Java生产配置。
- 开发服务排除`output`目录监听，浏览器截图、trace和报告不参与热更新；源码仍正常监听。避免验收产物持续写入拖慢日常页面，不改生产产物、代理或请求超时。
- 输出仍为`dist/static`，部署根路径`/`，关闭source map；gzip插件生成压缩副本，保留原文件。
- SVG使用构建时glob读取和本地symbol sprite，保留`icon-*`标识；Element旧图标字符串在展示边界转换，菜单及设计器配置不改名。
- 浏览器端Node path/util引用改为本地路径函数和Array.isArray；样式变量通过`.module.scss`导出。

## 4. 登录、路由、权限、Tab

- Router4采用createWebHistory，后端组件路径通过构建时glob映射；兼容`.vue`、目录index、Layout、ParentView、InnerLink。
- 动态注册使用addRoute并保存移除函数；登出清理动态路由及Tab。初始化复用并发Promise，失败后退出登录态、恢复进度和加载状态。
- 保持GetInfo→谷歌规则缓存→GenerateRoutes顺序。当前菜单首次匹配前可出现Router的No match调试警告，初始化后重新匹配，不等同于运行异常。
- 通配路径为`/:pathMatch(.*)*`；个人中心改密跳转使用query.activeTab，tab工具读取currentRoute.value。
- 权限/角色/剪贴板指令迁移Vue3生命周期，保留既有权限语义。
- RouterView通过插槽组合Transition、KeepAlive；切换主题重建缓存容器，避免旧主题页面和teleport弹窗残留。Tab列表本身保留。
- 双击Tab通过显式Sidebar引用、菜单公开open/close方法定位父级；不读取`__vue__`、`$children`或组件私有菜单状态。

## 5. 页面与公共组件

- `.sync`、`.native`、旧slot和销毁钩子迁移为Vue3语法；自定义输入/上传/编辑器使用modelValue和update:modelValue。
- 单选、多选显式value，日期格式符号适配Element Plus，提交Java的日期字符串格式不变。
- TreeSelect保留normalizer、节点计数、搜索、清空、禁用和父节点选择，ID不强制转字符串。
- 保留四档布局尺寸及旧Cookie；Element Plus基础尺寸映射配合密度CSS区分。
- JSX、VNode和函数式菜单组件迁移为Vue3实现；保留原列表、表单校验、详情和操作入口。
- 菜单图标与标题不包在同一个span内，叶子菜单标题使用Element Plus的title插槽；折叠时只隐藏标题，顶层图标在54px侧栏居中，适配新的el-menu-tooltip__trigger。各级子菜单用teleported替代旧popper-append-to-body，避免嵌套弹层被父级裁剪；二级标题复用主题文字色。
- Cron生成器直接读取已声明props，源码检查禁止Vue2的$options.propsData访问。表达式回显时数字字段显式转数值，保留Quartz星期#参数顺序及年份；预览复用主题变量，确认仅回填任务草稿，不自动保存/执行任务。
- 角色菜单/部门树与角色详情齐备后才打开表单，失败清理旧树并释放加载标记；读取helper返回Promise，由消费方处理。字典、任务日志初始化失败结束加载，搜索重试保留入口的类型/任务上下文。
- 缓存详情显式使用readonly；切换名称和键名后忽略旧响应，读取失败清除旧详情。刷新成功提示只在成功响应后显示，保存/清理拒绝仍由页面收尾，不修改接口或权限。

## 6. 请求、上传和富文本

- Axios原协议、GET参数、防重复提交、401/500/601、谷歌错误码-1001/-1002/-1003和文件流分支保留。
- 列表、缓存、监控及辅助选择弹窗补齐失败收尾；错误仍由请求拦截器显示，失败后释放加载并允许重试。下载安全验证取消后不发送请求、不追加下载故障提示，也不输出含凭据的Axios配置。
- 验证弹窗取消会拒绝目标请求且不报成网络异常；参数页提交在取消时保留表单。
- el-upload仍直传，显式使用Token和业务状态码；不改变直传与Axios的验证码触发边界。
- 文件与图片上传保留类型、大小、文件名、排序和历史响应字段；失败时校正并行上传计数，卸载释放Sortable。
- Quill2实例和ECharts实例使用markRaw，释放事件及图表资源。富文本HTML存储格式不变；图片选择使用受控file input，不访问上传组件内部子实例。
- 富文本粘贴图片与选图入口复用现有格式和fileSize校验，非法图片不发送上传请求；模拟paste事件与真实系统剪贴板分别记录验收结果。
- vue-cropper使用Vue3版本及其CSS，保留旋转、缩放、裁剪Blob和头像上传字段。
- 文件管理和公共ImagePreview显式启用preview-teleported，预览层挂到body，避免表格毛玻璃和裁剪容器限制覆盖范围。图片预览工具栏、关闭及多图切换按钮使用深色中性底、白色图标，不沿用主题文字变量作为背景。

## 7. 八主题与设计器

保留轻奢商务、毛玻璃、活力科技、极简未来、温馨自然、质感设计、高端暗黑和default；保留背景、主色、持久化、菜单特效和音效。旧el-submenu样式同步为el-sub-menu，深度选择器使用`:deep()`。

Element Plus固定列使用sticky单元格而非Element UI镜像表，统一沿用`--zero-fixed-table-*`变量；新输入wrapper、弹层、表格、分页使用全局主题变量。设置抽屉保持非模态，不阻挡页面按钮。主色切换使用CSS变量，不再下载替换旧主题CSS。

浏览器续验补修：全局ThemePicker保留主色初始化但不渲染颜色控件，防止刷新时左上角闪现。设置栏在外部点击、Esc、关闭按钮和保存成功后收起，自己的主题/颜色弹层不误触发关闭；卸载释放外部点击监听。角色菜单、部门权限树恢复为操作选项在上、树占满下一行；数字input不重复绘制内部背景，禁用输入框使用主题变量，数据权限弹窗标签宽度与角色编辑统一。

系统弹窗、MessageBox确认框和输入提示框去掉Plus外层padding、边框和阴影，标题/内容/底部直接贴合容器，保留主题颜色、内部表单间距和输入校验。确认框覆盖规则限定实际消息遮罩容器，优先级高于旧主题的:not选择器，避免毛玻璃深色厚边残留。菜单点击改为链接、父菜单根元素的原生DOM事件；点击动画优先于持续激活动画，水波纹/脉冲使用独立图层，避免覆盖主题选中标记。重复点击、切换效果和卸载均清理图层及定时器。

设计器保留字段JSON、拖入、嵌套、克隆、复制、删除、排序和右侧属性。Vue3拖拽使用item-key/#item；render/生成HTML/JS同步适配。旧时间范围转换为Element Plus禁用回调；页面与弹窗导出均编译验证，页面导出另做浏览器挂载验证。正则生成不再执行eval。

实际拖拽补修：Element Plus行布局为flex，空行容器及主画布表单显式width:100%，空提示不拦截指针，不再收缩为零宽；初始字段为空时使用空对象兜底。重建页面从已有字段最大ID继续递增；剪贴板实例和body drop监听随组件卸载释放，drop仅阻止浏览器默认打开文件，不阻断Sortable的document收尾。嵌套行导出的gutter显式绑定为数字，行内字段始终保留el-col，按原span占满或分栏，避免原span24字段挤在一行。实际下载的页面、弹窗两类组件均增加挂载、列宽/顺序、填写、校验及重置/关闭验证。

后端代码生成保留原接口与Vue2/Vue3模板选项。仓库未找到Java引用的vm资源；2026-11-16重新核对当前admin进程的1个classes目录及171个依赖JAR，同样未找到引用模板，未知来源为空。来源检查已完成，实际生成仍未验收；不补模板、不修改Java。

## 8. 验证与后续上线条件

2026-11-16代码生成专项：字段表格按Element Plus的tbody结构挂载拖拽，卸载释放实例；必要详情与选项齐备后提交。配置从页面info取值，不依赖表单实例公开旧model；初始化重匹配显式保留query与hash。创建、导入、生成和预览失败由页面消费拒绝，保持原接口协议。后端模板资源和真实生成仍单独待验证。

真实服务联调补修：外链与站内路由分开消费、Layout统一异步加载、刷新中转页在mounted后跳转、旧UMD加密库正确取构造函数。Element Plus非元素根节点的下拉菜单项使用现有$auth控制渲染，其它权限按钮仍沿用指令。输入wrapper/inner装饰分离，布局大小触发区居中，表格下拉操作与普通按钮垂直对齐；全部八主题均列入回归。

具体结果见`02-功能与主题验收清单.md`。只有测试证据支持的条目记为通过；mock流程不代替Nacos、Redis、数据库、存储和跨服务真实联调。全部必测项通过后才发布，发布与回退见第三份文档。
